墨奇输入板 MoqiPanel 使用说明
================================

这是什么
--------
绿色免安装的中文输入面板：不注册输入法、不改注册表，所有文件都在本文件夹里。
在没有（也不想装）中文输入法的英文系统上，用它打中文、翻译成英文，再粘贴到别的程序里。

怎么用
------
1. 双击 MoqiPanel.exe。第一次启动要部署词库，大约十几秒；状态栏显示"输入引擎就绪"后就可以打字。
2. 在输入区用全拼打字：空格或数字键选词，- / = 或 PgUp / PgDn 翻页，回车把字母原样上屏，Esc 清除组字。
   上屏的文字累积在输入区，可以继续编辑。
   标点打出来就是英文标点（, . ? ! ; : " ' ( ) [ ] { } $ 等，中文状态下也是），
   这是面板包自带的配置，和墨奇输入法本体的中文标点不一样。
3. 按 Shift 或点左上角的"中 / 英"切换中英文。
4. 复制（所有复制到剪贴板的文字，中文标点都会换成英文标点；粘贴进来的文字带中文标点也会换掉）：
   - 选中文字即自动复制（鼠标拖选、双击选词、Shift + 方向键、Ctrl + A）；
   - 【复制原文】：复制整个输入区；
   - Ctrl + Enter 或【翻译并复制】：把输入区翻译成英文，复制译文，然后清空输入区；
   - 【重新复制】：再复制一次上次的译文；
   - 【恢复】：把刚清掉的原文放回输入区。
5. 到目标程序里点进输入框，Ctrl + V 粘贴。

翻译设置
--------
点【翻译设置…】，填三项：接口地址（OpenAI 兼容的 /chat/completions）、API 密钥、模型；
先点【测试连接】确认能通，再点【保存】。
设置保存在本文件夹的 translate.json，也可以直接用文本编辑器改，每次翻译前都会重新读取。
- 代理：留空用系统代理；填 direct 直连；或填 http://主机:端口
- 默认模型 deepseek-flash；对 deepseek 系模型默认关闭思考（不额外出思考内容）。
- 附加参数：JSON 对象，会并入请求，例如 {"thinking":{"type":"enabled"}}（打开思考）
- 单次最多翻译 256 个字（汉字、字母、标点各算一个），超了请分段。
- 翻译失败时，输入区、结果区、剪贴板都不会动。
- 结果区只保留最近一次，原文和译文都可以选中复制。

注意
----
- 文件夹路径只能是英文、数字和普通符号（引擎依赖的数据库组件不支持中文路径，路径不对会提示并拒绝启动）。
- 文件夹必须可写（U 盘可以，光盘不行）。
- 关闭窗口即退出，不留后台进程。
- user\ 文件夹里是学习数据、日志和窗口位置，随时可以整个删掉，删了就恢复初始状态。
- 升级：用新版的 MoqiPanel.exe、MoqiDaemon.exe、rime.dll 和 moqi-ime\ 覆盖旧文件即可（首次启动会自动
  重新部署，大约十几秒）；translate.json 和 user\ 不会被覆盖。
- 想让面板打中文标点：删除 moqi-ime\input_methods\rime\data\default.custom.yaml，
  然后重新启动面板（会自动重新部署，大约十几秒）。
- fonts\ 是随包的思源黑体（Noto Sans SC，SIL OFL 1.1），只在系统没有微软雅黑时使用。
